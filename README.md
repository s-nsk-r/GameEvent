# Phase Courier: Will of the Continuum

A dimensional platformer built for the Game Jam, featuring seamless open-world traversal, dynamic 2D lighting, and fluid momentum.

---

## 🕹️ Controls (STRICTLY 6 KEYS)

| Key | In-Game Action |
| :--- | :--- |
| **`Left Arrow`** | Move Left |
| **`Right Arrow`** | Move Right |
| **`Up Arrow`** | Jump / Wall-Leap / Aim Up |
| **`Down Arrow`** | Duck / Interact with Tablets |
| **`Z`** | **Primary Action / Air-Dash / Start / Confirm / Restart** |
| **`Space`** | **Secondary Action: Dimension Phase** (Solar Gold $\leftrightarrow$ Void Cyan) |

*Both `z` and `Z` are supported.*

---

## 🚀 How to Run

### Method 1: Web Browser (Instant, No Installation)
1. Double-click `index.html` to open it in Chrome, Edge, Firefox, or Safari.
2. Press **Z** on the title screen to start playing!

### Method 2: Godot Engine 4
1. Open **Godot 4** (4.0+).
2. Click **Import**, navigate to this folder, and select `project.godot`.
3. Press **F5** (or the Play button) to run the main scene.
